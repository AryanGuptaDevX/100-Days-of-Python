# 🐍 Day 1 — Programming & Python

### What is Programming?

* Programming = **giving instructions to a computer**.
* Computers follow instructions exactly as given.
* Programming helps us automate tasks and perform complex calculations.

### What is Python?

* Python is a **high-level, interpreted, dynamically typed** programming language.
* Supports **Object-Oriented** and **Functional Programming**.
* Created by **Guido van Rossum** in **1989**.

### ⭐ Features of Python

* Simple and easy to learn
* Interpreted & platform-independent
* Open-source
* Huge library support
* Can integrate with other programming languages

### 💻 Uses of Python

* 🤖 AI & Machine Learning
* 📊 Data Analytics & Visualization
* 🌐 Web Development
* 🗄️ Database Management
* 🧮 Business & Accounting
* 👁️ Computer Vision

### 📝 One-line Revision

**Python = Simple + Powerful + Versatile programming language used in Web, AI, Data, Automation, and more.**
