# 🐍 Day 7 — Operators & Arithmetic

### 🔧 What are Operators?

**Operators** are symbols used to perform operations on values or variables.

### ➕ Arithmetic Operators

| Operator | Operation           |   Example |     Result |
| -------- | ------------------- | --------: | ---------: |
| `+`      | Addition            |  `15 + 7` |       `22` |
| `-`      | Subtraction         |  `15 - 7` |        `8` |
| `*`      | Multiplication      |   `5 * 7` |       `35` |
| `/`      | Division            |   `5 / 3` | `1.666...` |
| `**`     | Exponent/Power      |  `5 ** 3` |      `125` |
| `%`      | Modulus (remainder) |  `15 % 7` |        `1` |
| `//`     | Floor Division      | `15 // 7` |        `2` |

### 💻 Example

```python
n = 15
m = 7

print(n + m)   # 22
print(n - m)   # 8
print(n * m)   # 105
print(n / m)   # 2.142857...
print(n % m)   # 1
print(n // m)  # 2
print(n ** m)  # 170859375
```

### 🧠 Important

* `/` → gives **normal division**
* `//` → gives **floor division**
* `%` → gives **remainder**
* `**` → means **power**

### 📝 One-line Revision

**Operators perform operations; arithmetic operators are `+`, `-`, `*`, `/`, `**`, `%`, and `//`.**
